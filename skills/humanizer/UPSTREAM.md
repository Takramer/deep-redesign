# Where this comes from

Bundled copy of the humanizer skill by Siqi Chen, https://github.com/blader/humanizer, MIT license (see LICENSE). It is included so deep-redesign's copy pass works from one install. The only change from upstream is a short Orwell pre-check section. To get updates, install upstream instead: `npx skills add blader/humanizer`.

Voice matching: the skill can match a writing sample. Give it the site owner's own writing (a file of their emails or posts) when the copy must sound like them.
